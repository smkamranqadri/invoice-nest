  <action>
    1. Create `middleware.ts` at the project root (NOT in src/) following Pattern 3 from the research:
       ```typescript
       import { NextRequest, NextResponse } from "next/server";
       import { getSessionCookie } from "better-auth/cookies";

       export function middleware(request: NextRequest) {
         const sessionCookie = getSessionCookie(request);

         // Protected routes: redirect to sign-in if no session cookie
         if (!sessionCookie) {
           return NextResponse.redirect(new URL("/sign-in", request.url));
         }

         return NextResponse.next();
       }

       export const config = {
         matcher: [
           // Protect dashboard and all nested routes
           "/dashboard/:path*",
           "/create-workspace",
           "/settings/:path*",
           "/members/:path*",
         ],
       };
       ```

       IMPORTANT: This is an OPTIMISTIC check (cookie existence only, no DB lookup). Full session validation happens in server components via `auth.api.getSession()`. This keeps middleware fast per the research recommendation (Pitfall: do NOT do full session validation in middleware).

    2. Add logic to the auth layout to redirect authenticated users AWAY from auth pages. In `src/app/(auth)/layout.tsx`, add a server-side check:
       - Import `auth` from `@/lib/auth` and `headers` from `next/headers`
       - Call `auth.api.getSession({ headers: await headers() })`
       - If session exists, `redirect("/dashboard")`
       - This prevents logged-in users from seeing sign-in/sign-up pages

    3. Create `src/components/auth/sign-out-button.tsx` -- client component:
       - Button that calls `authClient.signOut()` from `@/lib/auth-client`
       - On success: redirect to /sign-in using `router.push`
       - Can be styled as a dropdown menu item or standalone button (will be used in the dashboard header later)

    IMPORTANT: The middleware matcher MUST NOT include `/api/auth` routes -- better-auth needs unauthenticated access to its own API endpoints for login/signup to work.
