<task type="auto">
  <name>Task 2: Create customer query functions and server actions</name>
  <files>
    src/lib/queries/customer.ts

  <action>
    1. Create `src/lib/queries/customer.ts` with two functions:

       `getCustomers(organizationId: string, options?: { search?: string; status?: "active" | "inactive" | "all" })`:
       - Build conditions array starting with `eq(customer.organizationId, organizationId)`
       - If status is "active", add `eq(customer.isActive, true)`; if "inactive", add `eq(customer.isActive, false)`; if "all" or undefined, no status filter
       - If search is provided, add `or(ilike(customer.name, '%search%'), ilike(customer.email, '%search%'))!` (non-null assertion on or() per Drizzle typing)
       - Return `db.select().from(customer).where(and(...conditions)).orderBy(desc(customer.createdAt))`
       - Import from drizzle-orm: `eq, and, or, ilike, desc`

       `getCustomerById(organizationId: string, customerId: string)`:
       - Select from customer where `id = customerId AND organizationId = organizationId`
       - Return `result ?? null`

    2. Create `src/lib/actions/customer.ts` with `"use server"` directive and three actions:

       `createCustomer(input: unknown)`:
       - Call `getRequiredOrganization()` for organizationId
       - Parse input with `createCustomerSchema.safeParse(input)`
       - If invalid, return `{ error: "Invalid customer data" }`
       - Insert into customer table with `id: createId()`, organizationId, name from parsed.data, email/phone/address as `parsed.data.field || null` (convert empty strings to null)
       - Call `revalidatePath("/customers")`
       - Return `{ data: newCustomer }`

       `updateCustomer(customerId: string, input: unknown)`:
       - Call `getRequiredOrganization()` for organizationId
       - Parse input with `updateCustomerSchema.safeParse(input)`
       - If invalid, return `{ error: "Invalid customer data" }`
       - Update customer set name, email/phone/address (empty to null), where `id = customerId AND organizationId = organizationId`
       - If no row returned, return `{ error: "Customer not found" }`
       - Call `revalidatePath("/customers")` and `revalidatePath("/customers/${customerId}")`
       - Return `{ data: updated }`

       `toggleCustomerStatus(customerId: string)`:
       - Call `getRequiredOrganization()` for organizationId
       - Select current `isActive` from customer where `id = customerId AND organizationId = organizationId`
       - If not found, return `{ error: "Customer not found" }`
       - Update customer set `isActive: !existing.isActive`
       - Revalidate both paths
       - Return `{ data: updated }`

    Imports: db from "@/lib/db", customer from "@/lib/db/schema", createId from "@paralleldrive/cuid2", eq/and from "drizzle-orm", revalidatePath from "next/cache", getRequiredOrganization from "@/lib/queries/workspace", schemas from "@/lib/validations/customer".
  </action>
