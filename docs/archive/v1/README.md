# InvoiceNest v1 archive

Reference material kept from the first InvoiceNest prototype (July–August 2025, Next.js 15 +
Prisma + SQLite). That codebase was retired in October 2026; the current app is a rewrite.

Nothing in this folder is wired into the app. It is kept for reference only.

| File | What it is |
|---|---|
| `spec.md` | The original product specification |
| `plan.md` | The original build plan |
| `database-schema.md` | v1's Prisma data model, described |
| `api-documentation.md` | v1's REST API |
| `countries.ts` | A ready-made country list for an address dropdown |
| `logo.png` | The v1 logo, 1024×1024 |

Ideas from v1 and the other early prototypes are collected in
[`../potential-ideas.md`](../potential-ideas.md).
